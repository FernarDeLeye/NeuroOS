# NeuroOS 0.1.0-alpha.1 — limited public alpha candidate

Offline conversational Linux agent, local GGUF/llama.cpp backend, persistent terminal
conversations/tasks, rootless commands, controlled publication, independent checks
and bounded repair. Apache-2.0 own code; dependencies/models retain separate licenses.
No weights, private histories, developer databases or automatic telemetry included.

Debian13 amd64 CPU-only is the target. This artifact is built and locally checked,
but clean apt install/upgrade/removal and a real second-machine dialogue are not yet
confirmed. See VALIDATION.md/report. Do not use for critical system administration.
CPU responses may take minutes; models/references and arbitrary goals can fail.

upload or visibility change is authorized by creating this candidate. Please read
INSTALL, KNOWN_ISSUES, SECURITY and report failures with sanitized synthetic examples.
